# 数据说明

已下载 C-Eval 的计算机网络验证集前 10 条（用于尝试基础知识问答评价）；文件保存在被忽略的 `data/ceval_computer_network_val.json`，不随仓库发布。来源：https://huggingface.co/datasets/ceval/ceval-exam ，许可为 CC BY-NC-SA 4.0；本项目是非商业实习研究，下载或传播仍需遵守许可。该数据不是视频分镜分类集，也不能单独证明视频质量或学科通用性。

`evaluation/classification_cases.json` 是本项目自写的 12 条试验分镜，由 AI 助手按预设类别标注，尚未由独立标注者核验，不能描述为公开数据或正式基准，也未用于训练模型。
